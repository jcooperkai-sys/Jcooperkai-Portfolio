INTERPRETABILITY · WORKING PAPER V1.0 · 2026-09-10

Causal-State Interpretability
What a neural network's features actually are, how many it has, and a way to count them that
never merges two different ones
Jeffery Eckert · independent research

Interpretability has no agreed answer to a basic question: what is a feature? The usual answer
— a direction in activation space — has a known failure: a direction can be perfectly readable
from a network and still do nothing. We replace it. A feature is a causal state: two internal
configurations are the same feature exactly when intervening on either produces the same
future behaviour. That definition is forced rather than chosen — it is the unique minimal
statistic that preserves behaviour — and it automatically discards information a network carries
but never uses. On a controlled system, an unused signal that is 100.0% readable from the
activations leaks 1.0000 bits into ordinary clustering and 0.0001 — the measurement floor —
into the causal one: more than 10,000× less, from the same activations. Grouping by
intervention also recovers the network's algorithm, not just its features: transitions between the
recovered states reproduce the generating machine to within 0.0154.
The definition left one question open, and it stopped the program: how many states are there?
We show the obvious estimator measures the sample rather than the network — the count at
fine resolution grew from 103 to 414 for 30× more data against a true answer of 3 — which
makes the program's own lower bound vacuous as first stated. We show why the standard
remedy, stability selection, cannot work here. And we give a method that does: coarsen until
compression stops being cheap, and stop at the first break. On fifteen unseen systems with 2 to
6 true states it recovers the exact count in 15/15, and no group it returns ever mixes two
true states (worst homogeneity 1.0000). Every error made on the way to the final method was
a split, never a merge. The guarantee holds with up to ε = 0.1 of each signature replaced by
estimation noise and fails abruptly by ε = 0.35 — a limit this paper measures rather than hides.
Everything here is toy-scale, and the paper says exactly where.

0 · How to read this paper
This paper merges two lines of work — a theory of what features are, and a method for counting them
— into one argument. Read it straight through and each section answers the question the previous one
raised. If you read nothing else, read this paragraph.

T he whole paper in one paragraph
Imagine a toy machine with a lid you cannot open. It has moods. Two moods are really the same
mood if poking the machine in either one makes it do the same thing next — watching is not
enough, because the machine can carry things it never uses. To count the moods, start with every
tiny difference as its own box and keep merging boxes that behave the same. Merging duplicates
costs nothing. The first merge that costs a lot would be putting a car in the same box as a bear.
Stop just before it: the boxes you have left are the real moods. The method sometimes leaves two
identical cars in different boxes — messy, harmless. It never puts a car in with a bear.

weight it can bear:

1 · A direction is not a thing the network has
Almost all interpretability rests on one assumption: a concept is a direction in the network's activation
space, and it is "present" to the degree the activation points that way. Probes, steering vectors and
sparse autoencoders all return directions.
The trouble is that a direction is a property of a coordinate system, not of the network. Rotate the basis
and the directions change while the computation does not. Sparse autoencoders make this concrete:
different seeds return different dictionaries, and a rare concept can be silently folded into a common
one — feature absorption — leaving a dictionary that looks clean and is wrong about exactly the
conditional concepts an auditor most needs.
Underneath both problems is a simpler one. Being able to read something off a network is not the
same as the network using it. Section 4 measures how large that gap can be. First we need a unit
that does not depend on coordinates.

2 · The definition: a feature is a causal state
Computational mechanics solved the analogous problem for random processes decades ago. Two pasts
of a process are equivalent when they predict the same future; the equivalence classes are the process's
causal states, and they are the smallest description that loses nothing about what comes next.

E stablished — causal states (C rutchfield & Y oung 1989; S halizi & C rutchfield 2001)
Two pasts x, x′ are causally equivalent iff P(future | x) = P(future | x′). The classes are the causal
states; their entropy Cμ is the statistical complexity — the number of bits the optimal predictor
must store.

A network's forward pass is not a process in time, so we make one change, and it is the important one:
we define equivalence by intervention rather than observation.

D efinition 1 — interventional causal state
Fix a layer ℓ with activations h. For activation vectors a, a′:

a ∼ a′ ⟺ P( Y | do(h = a) ) = P( Y | do(h = a′) )
The equivalence class of a is its causal state; the map σ sending each activation to its class is the
causal-state function. A feature is a causal state.

The do(·) is the whole point. Conditioning asks what can be read off an activation. Intervening —
setting the layer to a and running the rest of the network — asks what the network does with it.
Information that is present but never used cannot change the output under intervention, so it cannot
separate two states. Figure 1 shows the definition and, on its second row, how the rest of the paper
counts the states it defines.

3 · Why the definition is forced
A definition is only worth building on if it is not arbitrary. This one is pinned down by what it
preserves. Call a statistic T of the activations sufficient if the network's interventional behaviour can be
computed from T(a) alone.

T heorem 1 — minimality

σ is sufficient, and every sufficient statistic T determines it: σ = φ ∘ T for some φ. Hence
H[σ(h)] ≤ H[T(h)], with equality only when T is a relabelling of σ.
Honestly stated, this is the classical fact that a minimal sufficient statistic is the coarsest sufficient
partition (Fisher; Lehmann & Scheffé) — the same argument Shalizi and Crutchfield used for causal
states — carried into the interventional setting. The setting is new; the minimality argument is not. Its
consequence is what matters: every other description of a layer is a refinement of σ, so it carries
redundant structure unless it equals σ. Probes, dictionaries and circuits are all points on the far side
of this line.

T heorem 2 — unused information is discarded
If part of the activation has no effect on P(Y | do(h)), two activations differing only in that part lie
in the same causal state. σ is invariant to anything the network carries but does not use.

T heorem 3 — estimation error degrades gracefully
If the interventional signature is estimated within ε (sup-norm) and groups are merged at
tolerance τ around a representative, then any two activations placed in the same group have true
signatures within 2τ + 2ε. Error costs fidelity linearly, never catastrophically.

Theorem 3's constant was first written as τ + 2ε; numerical checking falsified that, because the
estimator merges by representative rather than pairwise, and the constant doubles. The corrected
bound holds in every configuration tested:

4 · Readable is not the same as used
Here is the gap between the two equivalence relations, measured twice on independent setups.
A recurrent network on a hidden Markov process. A small RNN is trained to predict the next symbol
of a 3-state hidden Markov process whose inputs carry an extra coin flip that has nothing to do with
anything. It reaches loss 0.9898 against a Bayes-optimal 0.9911 (uniform guessing: 1.0986), and its
hidden state encodes the true belief state linearly with held-out R² = 0.98. The coin flip is readable
from its activations with accuracy 1.00. Yet flipping it moves the output by only 0.0335 of a typical
difference between states. Perfectly readable; essentially unused.
A feedforward network on a source with known states. Here the interventional distribution can be
computed exactly, so this tests the definition itself with no estimator in the way. Across 5 seeds, an
unused nuisance channel is 100.0% decodable from the hidden layer. Grouping raw activations and
grouping by intervention then disagree about what counts as structure:

5 · The wall: how many states?
Section 4 cheated in one respect: it told the clustering there were 3 states. A method for unknown
networks has to find the number. This is where the program stopped, and the reason turned out to be
more interesting than a tuning problem.
The natural estimator is the definition taken literally: group activations whose signatures agree exactly
— tolerance zero — and count. Figure 3 shows what that measures.

Figure 3. The obvious estimator measures the sample, not the network. Counting states at zero tolerance
gives 103 states from 200 samples and 414 from 6,000, while the true answer is 3. Statistical complexity rises
with it, from 6.16 to 7.33 bits.
states found at tolerance → 0

truth

The count went from 103 states on 200 samples to 414 on 6,000 — 4.0× more states for 30× more
data — and was still climbing. The truth is 3. Statistical complexity rose with it, from 6.16 to 7.33 bits.
At zero tolerance the estimator is counting the sample, not the network: finitely many samples of
a continuous signature never coincide exactly, so almost every point becomes its own class.
That has a consequence for the theory. The program's keystone was a lower bound: no faithful
explanation of a layer can be shorter than Cμ bits.

T heorem 4 — the lower bound , stated where it can be measured
For the exact quotient, every faithful explanation has entropy at least Cμ (Appendix A). But Cμ
estimated at tolerance → 0 grows without bound in the sample size, so the bound in that form
binds nothing. The usable statement is at fixed distortion: every explanation with expected
distortion ≤ D needs at least R(D) bits, where R is the rate–distortion function of the
interventional source, and R(0) = Cμ. The limit D → 0 must be taken after n → ∞, not before.

So the honest object is not a number but a curve: how many bits of explanation buy how much fidelity.
And the structure is on that curve — at the right tolerance the same data give exactly 3 states that
agree with the truth at ARI 0.985. The problem is purely that nothing yet says where on the curve to
stand.

6 · Why "does it replicate?" cannot answer it
The standard answer to "how many clusters?" is stability selection: choose the resolution at which
independent halves of the data produce the same grouping. It is widely used, and here it fails for a
structural reason worth stating plainly.

Figure 4. Stability selection cannot find the scale. Splitting the data in half and asking whether both halves
group the same way scores 0.972 at about 187 states — as high as the true structure's 0.963 at about 3. A
finely-sampled smooth cloud can be cut the same way twice simply because it is smooth.
replication, corrected for chance

At the finest tolerance, with about 187 states, the replication score is 0.972. At the true structure,
about 3 states, it is 0.963. In between it dips to 0.602. The meaningless answer replicates as well as

the right one.

M easured — the failure mode
Any criterion built on partitions agreeing rewards the trivial partition. When almost every
point is its own group, two halves that densely cover the same smooth cloud assign a fresh point
to the same nearest neighbour — reproducibly, and meaninglessly. Fine partitions of a smooth
manifold replicate because the manifold is smooth, not because it has structure.

Two natural repairs fail too, in exploratory runs kept in the repository rather than reproduced here.
Dividing replication by the bits it costs diverges as the cost goes to zero, so it drifts toward a single
group. Subtracting a structureless control fails unless the control is matched on rate rather than on
tolerance. The lesson generalises beyond this paper: reproducibility is necessary and nowhere near
sufficient. What is needed is a signal the smoothness cannot fake.

7 · The method: stop where compression stops being cheap
That signal was sitting on the rate–distortion curve. Merging two groups that behave the same costs
almost no fidelity; merging two that behave differently costs a lot. So walk the curve from fine to
coarse and watch the price of each merge (Figure 5).

Figure 5. Where compression stops being cheap. Each bar is one merge step. Merging redundant groups
costs almost nothing, and those bars sit on a flat baseline. The first step that breaks it — 3 groups to fewer —
costs 25× the baseline. The method stops just before it and returns 3. On this system the first break happens
also to be the last merge, to a single group. In general the largest step is that final collapse and can come
after the real break, which is why the rule takes the first break rather than the largest.
redundant merge

first real merge

Going from 256 groups down to 3 costs very little — distortion moves from 0.0007 to 0.0395. The
next merge, to 1, costs 25× the baseline set by every cheaper merge before it. That step destroys real
structure. The method stops just before it and returns 3.

D efinition 2 — the first structural break
(1) Index the curve by distinct group counts, never by tolerance: many tolerances give the same
grouping, and dividing by a near-zero change in rate manufactures enormous costs out of
nothing. (2) Walk from fine to coarse and take the first merge whose cost exceeds the median of
all cheaper merges by a threshold — not the largest merge, which is always the final collapse to a
single group. (3) Return the grouping just before that merge.

Three details turn this rule into a method, and each came from a failure.
No threshold is chosen. A fixed threshold works, but choosing it after seeing the answer would make
the result self-fulfilling. Instead the method sweeps 112 thresholds and keeps the answer that survives
the longest run of them (Figure 6). The answer is not fragile: the longest run covers 101–112 of 112
thresholds across every test system. This is also the plateau an earlier attempt looked for and failed to
find — it was looking along the tolerance axis, where there is none. Along the threshold axis the
plateau is wide.

Homogeneity measures whether each returned group lies inside a single true state; 1.0 means
always. The worst homogeneity across all fifteen systems is 1.0000.

This is a soundness property rather than an accuracy score, and Theorem 1 says why it is the right one.
Every faithful description of a layer is a refinement of σ. A grouping that splits a true state is still a
refinement — still faithful, merely not minimal. A grouping that merges two true states is not faithful
at all: it asserts that two things which behave differently under intervention are the same. So the
method's errors can cost minimality, but never faithfulness. For an interpretability method, that is
the only error direction worth having.

9 · The two predictions, made measurable
The theory made two falsifiable predictions before any of the counting work existed. Both were run at
toy scale. What the counting method adds is the ability to test them directly.

9.1 Prediction I — absorption is the splitting of a causal state

P rediction I
A sparse-autoencoder feature that does not correspond to a causal state has no causal content:
nothing the network does depends on it, so nothing pins it down across training runs. Such
features should be unstable across seeds, and absorption is the special case of a feature that tries
to split a single causal state.

Figure 9. Prediction I, first contact (recorded). Features with more causal effect reappear more reliably in an
independently trained autoencoder: correlation +0.405; the most causal quarter has stability 0.607 against
0.535 for the least. A moderate effect on a toy model, not a knockout.
one SAE atom

On a grokked model of modular addition (test accuracy 0.96), 469 of 512 autoencoder features were
scored for causal effect and for whether they reappear in an independently seeded autoencoder. The
predicted relationship holds, moderately: correlation +0.405, with the most causal quarter at 0.607
against 0.535 for the least. The kill condition — a population of stable features with no causal effect —
did not appear.
Section 8 now gives the prediction a precise meaning. "Splits a causal state" is exactly homogeneity 1
with completeness below 1: every group sits inside one true state, but some state is spread across

several groups. That is measurable on any model where the counting method runs.

9.2 Prediction II — grokking is a collapse in causal-state count

P rediction II
A network that memorises needs roughly one internal state per training example; one that
generalises needs only the true machine's few. So when a network groks, its count of causal states
should collapse — and the collapse should come before test accuracy moves.

Figure 10. Prediction II, first contact (recorded). In 8 of 8 grokking runs the representation compresses
before test accuracy rises — by 4,675 ± 1,393 steps — and before the standard weight-norm signal in 8 of 8,
by 2,525 steps. The compression measured here is effective dimension, a proxy; §9.3 explains why the direct

9.3 Why the direct test needs the counting method
Those grokking runs measured effective dimension, a proxy. The planned direct test estimates the
causal-state count itself by grouping activations to some tolerance δ. Section 5 shows why that is
dangerous without a rule for δ, and grokking is where the danger bites. At small δ a spread-out
activation cloud splits into roughly one group per point regardless of its causal structure, and a
contracted cloud does not. Memorisation spreads activations; generalisation contracts them. A
"collapse" would therefore appear at the grok point even if the causal structure never changed —
geometric contraction wearing a causal-state label, which is the effective-dimension result again

under a new name. Choosing δ by the first structural break is what makes the direct test a test of the
prediction rather than of geometry.

10 · The larger program (conjecture)
Everything in this section is labelled conjecture. Nothing above depends on it; it is where the definition
leads if it holds up at scale.

C onjecture — the right distance is F isher –R ao
Causal states parameterise predictive distributions, and the only distance between distributions
that no choice of coordinates can distort is the Fisher–Rao metric (Čencov's theorem). Euclidean
distance between activations is interpretable only where the network happens to embed that
geometry faithfully.

C onjecture — the computation is a linear operator
On distributions over causal states, one step of computation is linear (the Koopman view). Its
eigenmodes are coordinate-free candidates for "natural features", and a sparsity objective that
ignores them should fragment them — a geometric account of absorption.

C onjecture — scale is a flow over prediction horizon
A model with finite capacity resolves causal states only up to some horizon. Ordering the
distinctions by the horizon at which they first matter gives a renormalisation-style ladder, in
which "emergence" is a distinction crossing the model's horizon.

One data point from a real language model is consistent with the starting assumption and does not
establish it. In Qwen2.5-0.5B, probing 600 sequences from a hidden Markov process, the belief state is
linearly decodable from layer 21 with R² = 0.892 — but a baseline that uses only the most recent
tokens reaches 0.835. The gap, 0.057, is small. It says the model carries belief-like information; it does
not say it carries more than recency explains.

there are, or bound explanation length. The closest competitor on derivation is Unsupervised Causal
Abstractions Discovery (arXiv 2606.19594), which obtains identifiability under an anchor assumption
and a factor-graph structure. It must be read in full before any priority claim. The apparent difference
is that it buys identifiability with assumptions about form, where this paper assumes nothing about
form and gives up exact identifiability for a soundness guarantee.
Much here is not new, and it should be said: causal states and statistical complexity (Crutchfield &
Young; Shalizi & Crutchfield); minimal sufficiency (Fisher; Lehmann & Scheffé); belief-state geometry
in transformers (Shai et al. 2024); elbow-style model selection (Thorndike 1953); the information
bottleneck (Tishby, Pereira & Bialek 1999); stability selection (Ben-Hur et al. 2002; Lange et al. 2004;
Meinshausen & Bühlmann 2010); homogeneity and completeness (Rosenberg & Hirschberg 2007). A
rate–distortion view of sparse autoencoders exists (arXiv 2605.14694) but does not select a number of
states, and a false-discovery-rate treatment of SAE features exists (arXiv 2511.11711) with a statistical
rather than a structural guarantee.
What I could not find stated elsewhere, and would bet on in that order: that the zero-tolerance
complexity estimate grows without bound in the sample (§5); that stability selection fails structurally
for this problem (§6); and soundness as refinement (§8). The knowledge cutoff behind this search is
May 2026, so this is a scan, not a literature review.

12 · Limits
The weakest section is §9. Both predictions are supported only by recorded toy-scale runs with
moderate effects (correlation +0.405; a lead measured with a proxy), and neither has been run with
the counting method that §9.3 argues it needs. It is argued more than tested.
What was synthetic. Every counting result uses feedforward networks on unifilar sources whose
causal states are finite and known. The estimation noise in §8 is simulated by mixing signatures with

random distributions, not incurred by a real estimator of P(Y | do(h)) on a real model. Nothing in §5–
§8 has touched a transformer.
Larger or smaller in the wild? Smaller, most likely. Real networks' causal states are approximate and
may form a continuum, so the break in the curve may be softer than here, and exact recovery rarer.
Soundness held longest in every test here, but §8 shows it can fail abruptly rather than gradually once
noise erases the break — so on a real model it should be checked, not assumed.
Two parameters remain, and one has a cost. The 1% mass floor and the smoothing level 0.20 are
fixed choices; neither is derived. Smoothing levels 0.20 and 0.25 recover every count with no mixing
at all, and 0.30 (worst homogeneity 0.9997) begins to mix. The cost is noise headroom: smoothing
and estimation error add, so the final method stays pure only to ε = 0.1, against 0.2 without
smoothing (§8).
The experiment not run. The method applied to a grokked modular-arithmetic transformer, with

P(Y | do(h)) estimated by real interventions, counting causal states across training. That single
experiment would test §8's guarantee on a real model and §9.2's prediction directly.
Do the limits change the direction of any result? Not for the negative results in §5 and §6, which
are about estimators and hold regardless of scale. Possibly for exact recovery at scale. The soundness
claim is the one to watch.

Appendix A · Proofs
Write g(a) := P(Y | do(h = a)). A statistic T is sufficient if g = ψ ∘ T for some ψ.
Theorem 1. Sufficiency: g is constant on each class by construction, so g = ĝ ∘ σ with ĝ([a]) := g(a) well
defined. Minimality: let g = ψ ∘ T. If T(a) = T(a′) then g(a) = g(a′), so a ∼ a′ and σ(a) = σ(a′); hence

σ = φ ∘ T. A function of a random variable has entropy no greater than the variable, so
H[σ(h)] ≤ H[T(h)]. ∎
Theorem 2. Write h = (u, z) where g does not depend on z. Then g(u, z) = g(u, z′) for all z, z′, so

(u, z) ∼ (u, z′): the classes, and σ, are unchanged by z. ∎
Theorem 3. Let ‖ĝ − g‖∞ ≤ ε and let a, a′ be merged with representative r, so ‖ĝ(a) − ĝ(r)‖ ≤ τ and

‖ĝ(a′) − ĝ(r)‖ ≤ τ. By the triangle inequality ‖g(a) − g(a′)‖ ≤ ε + τ + τ + ε = 2τ + 2ε. ∎
Theorem 4. Let (enc, dec) be faithful, so g = dec ∘ enc; then enc is sufficient and by Theorem 1

H[enc(h)] ≥ H[σ(h)] = Cμ; Shannon's source-coding theorem gives the code length. For distortion D:
any encoder S with expected distortion ≤ D is feasible for the minimisation defining

R(D) = min I(h; S), so H[S] ≥ I(h; S) ≥ R(D); at D = 0 the minimiser is σ, giving R(0) = Cμ. What §5
shows is that the finite-sample estimate of Cμ is not the Cμ of the theorem. ∎

Appendix B · The counting algorithm
1. Signatures. For each sampled activation a, compute or estimate g(a) = P(Y | do(h = a)).
2. Smooth. Replace each signature with 0.8 · g(a) + 0.2 · n, where n is drawn uniformly from the
simplex.
3. Curve. For a ladder of tolerances, group signatures by representative merging; record, for each
distinct group count, the rate (entropy of the grouping) and the distortion.
4. Break. For each threshold in a sweep, walk fine → coarse and take the first merge whose cost
per bit saved exceeds the threshold times the median of all cheaper merges.
5. Plateau. Keep the grouping whose count survives the longest run of thresholds.
6. Prune. Reassign points in groups holding under 1% of the mass to the nearest surviving group.
