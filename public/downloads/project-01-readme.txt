KAI AGENT LAB
=============

Status: ACTIVE

Kai Agent Lab is a hands-on sandbox for testing planning, tool use, memory,
recovery, and visible checkpoints in agentic AI workflows. Each experiment
starts with one narrow question and records both successful and failed runs.

Project home: https://jcooperkai.com/
Code profile: https://github.com/jcooperkai-sys
